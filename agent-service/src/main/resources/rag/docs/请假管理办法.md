# 值班请假管理办法

## 请假类型

第一条 值班请假分为四类：病假、事假、公假与调休。

第二条 病假指因病或就医无法值班；事假指因个人事务无法值班；公假指因学校或学院统一安排的活动无法值班；调休指因放假调休导致时间冲突。

## 申请流程与时限

第三条 请假应至少提前 3 个自然日提交申请；因突发情况无法提前申请的，应在值班开始前 2 小时内补交，并在事由中注明"突发"。

第四条 请假申请须填写：值班类型（宿舍/办公室）、请假起止日期、请假类型、事由；请病假的须上传就医凭证。

第五条 请假起止日期以自然日计算，跨周请假的按实际涉及的教学周分别统计。

## 审批权限

第六条 请假由分管管理员审批；连续请假 3 天以内的由组长初审、管理员终审。

第七条 审批通过的请假记录状态为 approved，会在排班生成时自动排除冲突人员。

第八条 请假申请被驳回的，状态为 rejected；申请人可补充材料后重新提交，不得就同一事由重复提交超过 2 次。

## 与排班冲突的处理

第九条 已批准请假涉及的时间段，系统在生成排班时自动跳过该人员，不受冷却规则影响。

第十条 若排班已生成后才批准请假，由管理员在排班表中删除该记录，并可从候选人员中补排。

## 撤销与变更

第十一条 请假申请在审批前可自行撤销；审批通过后如需取消，应联系管理员处理。

第十二条 请假日期发生变化的，应撤销原申请后重新提交。

## 违规处理

第十三条 未请假且未到岗的，按《纪律与考核办法》认定为缺岗。

第十四条 提供虚假材料骗取请假的，取消当学期评优资格并记入档案。

## 附则

第十五条 本办法由党群组织办公室负责解释。
