# 排班系统部署指南

## 📦 部署前准备

### 1. 服务器环境要求
- JDK 21（项目基于 Spring Boot 3.2 + Java 21，低于 21 会启动报错）
- MySQL 8.x (端口 3306)
- Redis 6.x+（缓存/分布式锁使用，端口 6379）
- Nginx
- Node.js (用于构建前端，可选)

### 2. 数据库配置

```sql
-- 登录 MySQL
mysql -u root -p

-- 创建数据库
CREATE DATABASE paiban_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 退出 MySQL
exit;
```

### 3. 后端打包

```bash
# 在项目根目录执行
mvn clean package -DskipTests

# 生成的 jar 包位置
target/paiban-1.0-SNAPSHOT.jar
```

### 4. 前端打包

```bash
# 进入前端目录
cd front

# 安装依赖(首次)
npm install

# 构建生产版本
npm run build

# 生成的 dist 目录
front/dist/
```

**重要提示：** 每次部署前端时，务必：
1. **删除服务器上的旧 dist 目录**
2. **上传全新的 dist 目录**
3. **清除浏览器缓存或强制刷新（Ctrl+Shift+R）**

## 🚀 部署步骤

### 1. 上传文件到服务器

```bash
# 上传后端 jar 包
scp target/paiban-1.0-SNAPSHOT.jar root@your-server-ip:/path/to/deploy/

# 方式1: 先删除服务器上的旧 dist 目录，再上传新的
ssh root@your-server-ip "rm -rf /var/www/paiban"
scp -r front/dist/ root@your-server-ip:/var/www/paiban

# 方式2: 使用 rsync 同步（推荐）
rsync -avz --delete front/dist/ root@your-server-ip:/var/www/paiban/
```

### 2. 修改后端配置

编辑服务器上的 `application.yml`：
- **数据库**：注释掉本地数据库配置，取消注释服务器配置（`root/change-me`）
- **附件上传目录**：将 `upload.dir` 改为服务器绝对路径，如 `/opt/paiban/uploads`，并确保目录存在且可写：
  ```bash
  mkdir -p /opt/paiban/uploads
  ```

### 3. 启动后端服务

> **前置**：确保 MySQL 和 Redis 已启动，否则后端无法正常连接数据库/缓存。
> 若服务器未安装 Redis：`apt install redis-server`（或 `yum install redis`），并 `systemctl start redis`。

```bash
# 方式1: 直接启动
nohup java -jar paiban-1.0-SNAPSHOT.jar > app.log 2>&1 &

# 方式2: 使用 systemd 管理(推荐)
# 创建服务文件: /etc/systemd/system/paiban.service
```

**systemd 服务配置示例:**
```ini
[Unit]
Description=Paiban Backend Service
After=syslog.target network.target

[Service]
Type=simple
User=root
WorkingDirectory=/path/to/deploy
ExecStart=/usr/bin/java -jar paiban-1.0-SNAPSHOT.jar
ExecStop=/bin/kill -15 $MAINPID
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
# 启用并启动服务
systemctl daemon-reload
systemctl enable paiban
systemctl start paiban

# 查看状态
systemctl status paiban

# 查看日志
journalctl -u paiban -f
```

### 4. 配置 Nginx

```bash
# 复制 nginx 配置
cp nginx.conf.example /etc/nginx/conf.d/paiban.conf

# 编辑配置，修改实际路径
vim /etc/nginx/conf.d/paiban.conf
```

**需要修改的内容:**
- `root /path/to/your/dist;` → 改为实际的 dist 目录路径
- `server_name` → 如果有域名，改为域名

```bash
# 测试配置
nginx -t

# 重载 Nginx
nginx -s reload
```

### 5. 访问测试

```
# 前端页面
http://your-server-ip

# 后端 API
http://your-server-ip/api/auth/login
```

## 🔧 配置切换说明

### 本地开发环境
- 数据库: localhost:3306, root/123456
- Redis: 127.0.0.1:6379
- 后端端口: 8080
- 前端代理: localhost:8080

### 服务器生产环境
- 数据库: localhost:3306, root/change-me
- Redis: 127.0.0.1:6379
- 后端端口: 8080
- 附件目录: upload.dir 改为 /opt/paiban/uploads
- Nginx 代理: 前端 → 后端 /api/

## 📝 注意事项

1. **数据库切换**: `application.yml` 中已注释好两套配置，按需切换
2. **JWT密钥**: 生产环境建议修改 `jwt.secret` 为更复杂的密钥
3. **日志管理**: 建议配置日志文件滚动策略
4. **备份数据库**: 定期备份 `paiban_db` 数据库
5. **防火墙**: 确保服务器只开放 80/443 端口

## 🐛 常见问题

### 后端启动失败
```bash
# 检查 JDK 版本
java -version  # 必须是 21

# 检查端口占用
netstat -nltp | grep 8080

# 查看详细日志
java -jar paiban-1.0-SNAPSHOT.jar --debug
```

### 前端 404
- 确保 Nginx 配置中有 `try_files $uri $uri/ /index.html;`
- 检查 dist 目录路径是否正确

### API 请求失败
- 检查后端服务是否正常运行
- 检查 Nginx 代理配置是否正确
- 查看后端日志

### Failed to fetch dynamically imported module
这是浏览器缓存了旧的 JS 文件导致的，解决方法：
1. **用户端**：强制刷新页面（Ctrl+Shift+R 或 Ctrl+F5）
2. **服务器端**：确保每次部署时完整替换 dist 目录（使用 `rsync --delete` 或先删除再上传）
3. **Nginx 配置**：已配置 `index.html` 不缓存，静态资源带 hash 可长期缓存
